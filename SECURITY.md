# Security Policy

*(日本語は下にあります / Japanese below.)*

## Supported versions

These are early-stage hobby projects. Only the latest commit on the default
branch of each repository is supported. There are no maintained release
branches or long-term support versions.

## Reporting a vulnerability

Please report security issues **privately** rather than opening a public issue.

- Preferred: open a private [GitHub Security Advisory](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)
  on the affected repository (Security → Report a vulnerability).
- Or email: **faces@rainorshine.asia**

When reporting, please include:

- the affected repository and commit,
- a description of the issue and its impact,
- steps to reproduce (a sample `.tmg1` or input is helpful),
- any suggested fix, if you have one.

We aim to acknowledge reports within a few days. Because this is a volunteer
project, fix timelines are best-effort. Please give us a reasonable window to
address the issue before any public disclosure.

# セキュリティポリシー

## サポート対象バージョン

本プロジェクト群は初期段階の趣味プロジェクトです。サポート対象は各リポジトリの
デフォルトブランチの最新コミットのみで、維持されるリリースブランチや長期サポート版は
ありません。

## 脆弱性の報告

セキュリティ上の問題は、公開 issue を立てず**非公開で**報告してください。

- 推奨: 該当リポジトリの非公開
  [GitHub Security Advisory](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)
  （Security → Report a vulnerability）から報告。
- もしくはメール: **faces@rainorshine.asia**

報告には以下を含めてください。

- 対象リポジトリとコミット
- 問題の概要と影響
- 再現手順（サンプルの `.tmg1` や入力があると助かります）
- 修正案（あれば）

数日以内の受領連絡を目指します。ボランティア運営のため、修正時期はベストエフォートです。
公開前に対応のための妥当な猶予をいただけると助かります。
